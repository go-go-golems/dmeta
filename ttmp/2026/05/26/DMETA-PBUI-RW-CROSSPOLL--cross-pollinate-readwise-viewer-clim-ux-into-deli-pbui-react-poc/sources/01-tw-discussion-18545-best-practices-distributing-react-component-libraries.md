<H3>rozsazoltan Jul 15, 2025</H3> <task-lists>  <p dir="auto">Simply add the <code>@source</code> directive like this to install your directory:</p> <p dir="auto"><strong>./css/globals.css</strong></p> <pre><code>@import "tailwindcss";
@source "../node_modules/my-package-name/dist;</code></pre> <p dir="auto">or</p> <p dir="auto"><strong>./css/globals.css</strong></p> <pre><code>@import "tailwindcss";
@source "../node_modules/my-package-name/dist/**/*.{js,ts,jsx,tsx};</code></pre> <p dir="auto">or just</p> <p dir="auto"><strong>./css/globals.css</strong></p> <pre><code>@import "tailwindcss";
@source "../node_modules/my-package-name;</code></pre> <p dir="auto">This expands the source file discovery to include not only the local project but also your UI components.</p> <p dir="auto"><strong>Important note</strong>: <em>It's important not to include the entire <code>node_modules</code> folder in your Tailwind content paths. Instead, always specify only your own package or component directories. This way, Tailwind's engine doesn't have to scan an enormous number of files and folders unnecessarily, which can lead to performance issues or misleading "not working" reviews - when in reality, it's just running very slowly and not recommended. So use minimum <code>/node_modules/my-package-name</code>; and don't forget the path is relative, so it depends on the location of your main CSS file - for example, in my case, I had to go up from the <code>./css</code> folder to reach the <code>node_modules</code> directory.</em></p> <p dir="auto">Live examples:</p> <ul dir="auto"> <li>HeroUI: <a
