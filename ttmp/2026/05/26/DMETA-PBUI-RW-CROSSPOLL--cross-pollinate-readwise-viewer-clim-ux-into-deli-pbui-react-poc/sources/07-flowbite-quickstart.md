<main> <H2>Flowbite - Quickstart</H2> <p>Get started with Flowbite by including it into your project using NPM or CDN</p> <div> <p>Flowbite is a library of components built on top of the utility-classes from Tailwind CSS and it also includes a JavaScript file that makes interactive elements works, such as modals, dropdowns, and more. Learn how to get started by following this quickstart guide.</p> <H2>Getting started</H2> <p>Flowbite can be easily integrated into your project through NPM. It functions as a plugin for Tailwind CSS and offers both a data attributes interface and a JavaScript API for powering interactive UI components.</p> <H3>Install using NPM</H3> <p>Make sure that you have <a href="https://nodejs.org/en/">Node.js</a> and <a href="https://tailwindcss.com/docs/installation/using-postcss">Tailwind CSS</a> installed. This guide works with Tailwind v4.</p> <ol> <li>Install Flowbite as a dependency using NPM by running the following command:</li> </ol> <div> <div> <ul> <li> Terminal </li> </ul> </div> <code>npm install flowbite</code> </div> <ol> <li>Import the default theme variables from Flowbite inside your main <code>input.css</code> CSS file:</li> </ol> <div> <div> <ul> <li> input.css </li> </ul> </div> <code>/* choose one of the following */

@import url('https://fonts.googleapis.com/css2?family=Inter:wght@300;400;500;600;700;800&amp;display=swap');
@import "flowbite/src/themes/default";

/* MINIMAL THEME
@import url('https://fonts.googleapis.com/css2?family=Open+Sans:ital,wght@0,300..800;1,300..800&amp;display=swap');
@import "flowbite/src/themes/minimal";
*/

/* ENTERPRISE THEME
@import url('https://fonts.googleapis.com/css2?family=Shantell+Sans:ital,wght@0,300..800;1,300..800&amp;display=swap');
@import "flowbite/src/themes/enterprise";
*/

/* PLAYFUL THEME
@import url('https://fonts.googleapis.com/css2?family=Google+Sans+Code:ital,wght@0,300..800;1,300..800&amp;display=swap');
@import "flowbite/src/themes/playful";
*/

/* MONO THEME
@import "flowbite/src/themes/mono";
*/</code> </div> <ol> <li>Import the Flowbite plugin file in your CSS:</li> </ol> <div> <div> <ul> <li> input.css </li> </ul> </div> <code>@plugin "flowbite/plugin";</code> </div> <ol> <li>Configure the source files of Flowbite in your CSS:</li> </ol> <div> <div> <ul> <li> input.css </li> </ul> </div> <code>@source "../node_modules/flowbite";</code> </div> <ol> <li>Include the JavaScript code that powers the interactive elements before the end of your <code>&lt;body&gt;</code> tag:</li> </ol> <div> <div> <ul> <li> index.html </li> </ul> </div> <code>&lt;script src="../path/to/flowbite/dist/flowbite.min.js"&gt;&lt;/script&gt;</code> </div> <p>Learn more about the Flowbite JavaScript API and functionalities in the <a href="https://flowbite.com/docs/getting-started/javascript/">JavaScript section</a>.</p> <p>If you have and old project with Tailwind CSS v3 then <a href="https://flowbite.com/docs/getting-started/quickstart/#tailwind-css-v3-to-v4">check out this guide</a> to learn how to upgrade to v4.</p> <H3>Include using CDN</H3> <p>The quickest way to get started working with Flowbite is to include the CSS and JS into your project via CDN.</p> <p>Require the following minified stylesheet inside the <code>head</code> tag:</p> <div> <div> <ul> <li> index.html </li> </ul> </div> <code>&lt;link href="https://cdn.jsdelivr.net/npm/flowbite@4.0.1/dist/flowbite.min.css" rel="stylesheet" /&gt;</code> </div> <p>And include the following JavaScript file before the end of the <code>body</code> element:</p> <div> <div> <ul> <li> index.html </li> </ul> </div> <code>&lt;script src="https://cdn.jsdelivr.net/npm/flowbite@4.0.1/dist/flowbite.min.js"&gt;&lt;/script&gt;</code> </div> <p>Please remember that the best way to work with Tailwind CSS and Flowbite is by purging the CSS classes.</p> <H3>Bundled JavaScript</H3> <p>One of the most popular way of using Flowbite is to include the bundled Javascript file which is UMD ready using a bundler such as Webpack or Parcel which makes sure that all of the data attributes and functionality will work out-of-the-box.</p> <p>You can directly import the main JavaScript file inside your bundled <code>app-bundle.js</code> file like this:</p> <div> <div> <ul> <li> app.js </li> </ul> </div> <code>import 'flowbite';</code> </div> <p>This file has access to all of the components and it automatically applies event listeners to the data attributes.</p> <H3>Data attributes</H3> <p>The preferred way to use the interactive UI components from Flowbite is via the data attributes interface which allows us to add functionality via the HTML element attributes and most of the examples on our documentation applies this strategy.</p> <p>For example, to set up a modal component all you need to do is use <code>data-modal-target</code> and <code>data-modal-{toggle|show|hide}</code> to toggle, show, or hide the component by clicking on any trigger element.</p> <H3>Init functions</H3> <p>You can also use the init functions to set up the event listeners yourself. Here’s an example how you can do it with Vue or Nuxt:</p> <div> <div> <ul> <li> app.js </li> </ul> </div> <code>&lt;script setup&gt;
import { onMounted } from 'vue'
import { initFlowbite } from 'flowbite'

// initialize components based on data attribute selectors
onMounted(() =&gt; {
    initFlowbite();
})
&lt;/script&gt;

&lt;template&gt;
    // Modal HTML markup with data attributes from Flowbite
&lt;/template&gt;</code> </div> <p>The <code>initFlowbite</code> function sets up all of the init functions for dropdowns, modals, navbars, tooltips and so on to hook onto the data attributes. Alternatively, you can also initialise each component category class separately with <code>initDropdowns</code> or <code>initModals</code>.</p> <p>You can view more examples by browsing the <a href="https://flowbite.com/docs/getting-started/quickstart/#components">components from Flowbite</a>.</p> <H3>ESM and CJS</H3> <p>Flowbite also offers an API for using the components programmatically and it supports both CJS and ESM for JavaScript which can be helpful if you need to expand the default capabilities of the data attributes interface and get access to function callbacks.</p> <p>Here’s an example how you can import and create a new Modal component inside JavaScript:</p> <div> <div> <ul> <li> app.js </li> </ul> </div> <code>import { Modal } from 'flowbite'

const $modalElement = document.querySelector('#modalEl');

const modalOptions = {
    placement: 'bottom-right',
    backdrop: 'dynamic',
    backdropClasses: 'bg-gray-900/50 dark:bg-gray-900/80 fixed inset-0 z-40',
    onHide: () =&gt; {
        console.log('modal is hidden');
    },
    onShow: () =&gt; {
        console.log('modal is shown');
    },
    onToggle: () =&gt; {
        console.log('modal has been toggled');
    }
}

const modal = new Modal($modalElement, modalOptions);

modal.show();</code> </div> <p>Check out the JavaScript behaviour section of each component’s page to learn how you can use this.</p> <H3>TypeScript</H3> <p>Flowbite supports type declarations for the interactive UI components including object interfaces and parameter types. Check out the following examples to learn how you can use types with Flowbite.</p> <p>Additionally to our code above, we will now import some relevant types from the Flowbite package, namely the <code>ModalOptions</code> and <code>ModalInterface</code>:</p> <div> <div> <ul> <li> app.ts </li> </ul> </div> <code>import { Modal } from 'flowbite'
import type { ModalOptions, ModalInterface } from 'flowbite'

// other code</code> </div> <p>Learn more about Flowbite and TypeScript in the <a href="https://flowbite.com/docs/getting-started/typescript/">quickstart guide</a>.</p> <H2>Tailwind CSS v3 to v4</H2> <p>If you want to upgrade v3 from Tailwind CSS with Flowbite you have to follow the <a href="https://tailwindcss.com/docs/v4-beta">v4 upgrade guide</a>.</p> <ol> <li>Install the next versions of Tailwind CSS and Flowbite using NPM:</li> </ol> <div> <div> <ul> <li> Terminal </li> </ul> </div> <code>npm install tailwindcss @tailwindcss/postcss postcss</code> </div> <ol> <li>Add the PostCSS plugin inside the <code>postcss.config.js</code> file:</li> </ol> <div> <div> <ul> <li> postcss.config.js </li> </ul> </div> <code>export default {

@config "../tailwind.config.js";</code> </div> <ol> <li>Compile the source CSS file using NPX:</li> </ol> <div> <div> <ul> <li> Terminal </li> </ul> </div> <code>npx @tailwindcss/cli -i input.css -o output.css</code> </div> <p>Now you should be good to go! Check the <a href="https://tailwindcss.com/docs/upgrade-guide#changes-from-v3">deprecated changes from v3</a> to learn more about the new features.</p> <H2>Tailwind CSS v3</H2> <p>We recommend you to follow the upgrade guide from v3 to v4 since Flowbite works with both.</p> <H2>Tailwind CSS v2</H2> <p>Flowbite works with the 2.x version of Tailwind CSS.</p> <H2>WindiCSS</H2> <p>Flowbite also works with WindiCSS by including the plugin inside the <code>windi.config.js</code> file:</p> <div> <div> <ul> <li> windi.config.js </li> </ul> </div> <code>plugins: [
