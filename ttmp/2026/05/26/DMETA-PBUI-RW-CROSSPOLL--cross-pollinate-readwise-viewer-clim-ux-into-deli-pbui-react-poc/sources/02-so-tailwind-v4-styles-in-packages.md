<div role="main" aria-label="question and answers">    <p>Why does my tailwind not work with my components in my <code>packages/components/src</code> files?</p> <p>It works in my <code>apps/my-app</code> but when I import my component from packages it does not apply TailwindCSS on my component.</p> <p>I have my <code>app.css</code> in <code>packages/styles</code>. What should I do?</p> 1      <div> <p>TailwindCSS v4 arrived with automatic source detection. This feature scans all files and searches for used class names to generate the compiled CSS. However, it ignores paths listed in the <code>.gitignore</code> file, meaning it typically skips <code>node_modules</code> directories; which is generally a good thing.</p> <ul> <li><a href="https://tailwindcss.com/docs/detecting-classes-in-source-files#which-files-are-scanned">Which files are scanned</a> - TailwindCSS v4 Docs</li> <li><a href="https://stackoverflow.com/a/79424690/15167500">Automatic Source Detection from TailwindCSS v4</a> - StackOverflow</li> </ul> <p>To make it detect custom packages despite <code>node_modules</code> being ignored by <code>.gitignore</code>, you can use the <code>@source</code> directive as follows:</p> <ul> <li><a href="https://tailwindcss.com/docs/detecting-classes-in-source-files#explicitly-registering-sources">Explicitly registering sources</a> - TailwindCSS v4 Docs</li> </ul> <p><strong>./src/app.css</strong></p> <pre><code>/* detects everything except the paths in the .gitignore file */
@import "tailwindcss";

/* if node_modules is ignored in .gitignore, it is possible to perform detection in its subdirectories */
@source "../node_modules/mypackage-first";
@source "../node_modules/mypackage-second/subdirectory/etc";</code></pre> <p>It is important to note that the path passed to the <code>@source</code> directive is relative and should be defined based on the location of the CSS file.</p> <p>If TailwindCSS doesn't detect anything, it's possible that you disabled source detection during import using <code>source(none)</code>. In this case, TailwindCSS will only scan the paths specified with the <code>@source</code> directive.</p> <p><strong>./src/app.css</strong></p> <pre><code>/* source(none) disables all detection, so it doesn't detect anything by default */
@import "tailwindcss" source(none);

/* in this case, it only detects the paths specified with @source */
@source "./"; /* relative path for src, since app.css in my example is located in src  */
@source "../node_modules/mypackage-first";
@source "../node_modules/mypackage-second/subdirectory/etc";</code></pre> </div> <p> Sign up to request clarification or add additional context in comments. </p>    </div>
